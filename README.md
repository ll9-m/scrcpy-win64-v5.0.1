# scrcpy 无线投屏（Windows 便携版）

基于 scrcpy 5.0.1 的免安装投屏包，附带一套本地无线连接脚本。
**整个文件夹可以随意复制、移动、换盘符**，双击即用，不写注册表、不装东西。

## 入口

双击 **`启动.bat`**，一个菜单搞定全部：

```
============================================================
  scrcpy 无线投屏
============================================================

  1. 配对手机        第一次使用，或手机换了 Wi-Fi
  2. 投屏            已经配对过，直接投
  3. 等待投屏        先开脚本，再开手机的无线调试
  4. 投屏设置        关屏 / 副屏 / 画质 / 窗口

  0. 退出
```

也可以直接指定动作：`启动.bat pair` / `mirror` / `wait` / `settings`。

想从桌面一键进入，运行 `tools\创建快捷方式.bat`，会在桌面生成带 scrcpy 图标的「投屏」。

## 目录结构

```
scrcpy-win64-v5.0.1/
├── 启动.bat                    统一入口（菜单）
├── 配对.bat                    配对（输入 IP:端口 + 6 位配对码）
├── 设置.bat                    投屏设置（按手机序列号保存）
├── 投屏.bat                    投屏
├── 等待投屏.bat                一直等手机出现再投屏
├── open_a_terminal_here.bat    在当前目录开一个命令行
├── scrcpy-noconsole.vbs        无黑窗启动 scrcpy
├── bin/                        程序本体（不要单独移动里面的文件）
├── config/                     phone.txt 记地址，devices/ 存每台手机的设置
├── docs/                       结构说明、许可证
├── tools/                      打包、创建快捷方式
└── logs/                       运行日志（自动生成）
```

## 第一次：配对（只需一次）

1. 手机打开 **开发者选项 → 无线调试**，并保持开启
2. 手机与电脑连同一个 Wi-Fi（不要开 VPN）
3. 手机点 **"使用配对码配对设备"**，记下弹窗里的 `IP:端口` 和 6 位配对码
4. 在菜单里选 `1`，依次填入上面两个值
5. 配对成功后脚本会去找投屏端口；找不到时会让你再填一次
   **"无线调试"主界面**上的 `IP:端口`（注意不是弹窗里那个）
6. 地址自动存进 `config\phone.txt`，之后选 `2` 直接投屏

> 为什么要填两次端口？配对端口和投屏端口是不同的两个端口，配对用的那个连完就失效了。

## 投屏设置

菜单里选 `4`。它认的是**手机序列号**而不是 IP——换 Wi-Fi、IP 变了，设置照样跟着这台手机走。
每台手机各存一份，换手机不会互相覆盖。

| 选项 | 说明 |
|---|---|
| 关屏投屏 | 手机屏幕黑掉，电脑照常看（省电、防偷看） |
| 虚拟副屏 | 给手机造一块虚拟屏，相当于外接显示器（需 Android 15+） |
| 剪贴板同步 | 电脑复制、手机粘贴，双向 |
| 分辨率上限 | 1280 / 1920 / 1024 / 不限制 |
| 帧率上限 | 60 / 30 / 90 / 不限制 |
| 视频码率 | 8M / 16M / 32M / 4M |
| 窗口形态 | 置顶 / 全屏 / 无边框 / 普通 |
| 保持亮屏 | 投屏时不让手机自动息屏 |
| 副屏启动应用 | **开了虚拟副屏必须填这一项**，否则副屏是空的、全黑 |

改完按 `0` 保存，配置写在 `config\devices\<序列号>.bat`，也可以直接编辑那个文件。

## 日志

每次配对、投屏都会在 `logs\` 下按天记一个文件（`2026-11-05.log`），内容包括：

- 设备发现结果、选中的设备
- 每次 `adb connect` / `adb pair` 的原始输出
- 最终执行的 scrcpy 命令行和退出码

投屏出问题时，先看这里——黑窗口一闪而过的信息都在里面。日志只保留最近 40 个文件，不会无限长。

## 打包

`tools\打包.bat` → 在 `dist\` 生成 `scrcpy-portable-5.0.1-<日期>.zip`（约 11 MB）。

用白名单收集文件，所以个人信息不会被打进去：`.git`、`.workbuddy`、`logs`、`dist`、
`config\phone.txt`、`config\devices\` 都不会进包。

## 常见问题

**为什么没有扫码配对**
scrcpy 的二维码配对要靠 mDNS 组播把手机的配对服务广播出来。校园网、企业网、公共 Wi-Fi
普遍会过滤组播，手机一直在等、电脑始终收不到，流程根本走不完。配对码方式是点对点 TCP，
不依赖组播，所以只保留这一条路径。

**首次运行弹出防火墙提示**
必须点"允许"（至少勾选专用网络）。如果误点了取消，会表现为"死活找不到手机"。

**找不到手机**
先在当前目录执行 `bin\adb.exe mdns check`，正常应输出 `mdns daemon version [...]`。
报错说明本机 mDNS 不可用，多半是 VPN、虚拟网卡或防火墙拦截了 UDP 5353。
不过校园网下即使 mDNS 正常，组播也可能在路由器侧被丢弃——这时只能靠 `phone.txt` 里的地址。

**配对成功但连不上**
正常现象：配对端口和投屏端口不是同一个，脚本会先自动找 `_adb-tls-connect._tcp`，
找不到就让你手输"无线调试"主界面显示的 `IP:端口`。

**虚拟副屏是黑的**
副屏是新建的一块空屏，上面没有桌面也没有任何界面。到设置里选 `9`，指定一个要启动的应用
（包名如 `com.android.settings`，或关键字如 `?bilibili`）。

**任务栏图标 / 断连画面不见了**
`bin\` 里必须同时有 `scrcpy.png` 和 `disconnected.png`，且要和 `scrcpy.exe` 放在一起。

## 改脚本注意

`.bat` 是 **GBK（GB18030 / 代码页 936）+ CRLF** 存的。用 VS Code 打开会显示乱码，
右下角把编码切成 `GB18030` 再保存，**不要存成 UTF-8**，否则中文全部失效。
每个脚本第二行都有 `chcp 936`，所以从任何终端启动都能正确显示。

`tools\lib\*.ps1` 是 **UTF-8 with BOM**，改动时注意别存成无 BOM。

结构说明见 [docs/markdown.md](docs/markdown.md)。
