# scrcpy 无线投屏（Windows 便携版）

基于 scrcpy 5.0.1 的免安装投屏包，附带一套本地无线连接脚本。
**整个文件夹可以随意复制、移动、换盘符**，双击即用，不写注册表、不装东西。

## 目录结构

```
scrcpy-win64-v5.0.1/
├── pair.bat                    配对（扫码 / 手输 6 位码）
├── mirror.bat                  投屏
├── mirror-wait.bat             一直等手机出现再投屏
├── open_a_terminal_here.bat    在当前目录开一个命令行
├── scrcpy-noconsole.vbs        无黑窗启动 scrcpy
├── bin/                        程序本体（不要单独移动里面的文件）
├── config/                     phone.txt 记录上次连上的地址
├── docs/                       结构说明、许可证
└── scripts/                    配对脚本与二维码生成库
```

## 第一次：配对（只需一次）

1. 手机打开 **开发者选项 → 无线调试**，并保持开启
2. 手机与电脑连同一个 Wi-Fi（不要开 VPN）
3. 电脑双击 **`pair.bat`**，直接按回车
4. 浏览器弹出二维码 → 手机上点 **"使用二维码配对设备"** 扫描
5. 配对成功后脚本自动连接，并把地址写进 `config/phone.txt`

> 手机上找不到"使用二维码配对设备"？
> 在 `pair.bat` 里输入 `M` 改用手输：填配对对话框里的 `IP:端口` + 6 位码。

## 日常使用

| 场景 | 操作 |
|---|---|
| 手机已连过同一 Wi-Fi | 双击 `mirror.bat` |
| 手机还没开无线调试 | 双击 `mirror-wait.bat`，开好后自动投屏 |
| 想用纯 GUI、不要控制台窗口 | 双击 `scrcpy-noconsole.vbs` |

连接顺序是自动的：先用已连接的设备，再试 `phone.txt` 里的地址，最后用 mDNS 找广播。

## 投屏参数

目前写在 `mirror.bat` 里：

```
--max-size=1280 --max-fps=60 --keep-active --always-on-top
```

想改分辨率或帧率，直接改这一行即可（`--max-size` 是长边像素上限）。

## 常见问题

**扫码后手机一直转圈（校园网 / 公共 Wi-Fi）**
这类网络通常开了客户端隔离，会直接丢掉 mDNS 组播：手机看不到电脑，电脑也看不到手机的广播。
**改用选项 2 手输**即可绕过——`adb pair` 是点对点 TCP，不依赖组播。配对后再填"无线调试"主界面的 `IP:端口`。
想彻底绕开：让电脑连**手机热点**，或直接插 **USB 线**（`mirror.bat` 本身支持 USB，完全不需要配对）。

**首次运行弹出防火墙提示**
必须点"允许"（至少勾选专用网络）。adb 的 `bin\adb.exe` 路径变了以后，旧的放行规则会失效；如果误点了取消，会表现为"死活找不到手机"。

**找不到手机**
先在当前目录执行 `bin\adb.exe mdns check`，正常应输出 `mdns daemon version [...]`。报错说明本机 mDNS 不可用，多半是 VPN、虚拟网卡或防火墙拦截了 UDP 5353。

**扫码一直超时**
1. 手机上的二维码页面关掉就失效，重新打开再扫
2. 两台设备必须同一 Wi-Fi；企业/公共 Wi-Fi 常开客户端隔离，会挡住 mDNS
3. 关掉 VPN、虚拟网卡再试

**配对成功但连不上**
正常现象：配对端口和投屏端口不是同一个，脚本会自动去找 `_adb-tls-connect._tcp` 的端口。若仍失败，用手机"无线调试"主界面显示的 `IP:端口` 手输一次。

**任务栏图标 / 断连画面不见了**
`bin\` 里必须同时有 `scrcpy.png` 和 `disconnected.png`，且要和 `scrcpy.exe` 放在一起。

## 开发与自测

二维码编码器是自己实现的（版本 4、纠错等级 M），不依赖网络和第三方库。改完可以这样验证：

```bash
node scripts/lib/qr.test.js            # 编码后反向解码，校验 RS 与格式信息
node scripts/lib/html.test.js  <html>  # 执行页面渲染脚本，比对生成的模块
```

结构说明见 [docs/markdown.md](docs/markdown.md)。
